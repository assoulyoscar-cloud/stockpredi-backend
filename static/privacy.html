2. Données collectées

StockPredi collecte uniquement les données strictement nécessaires pour fonctionner:

Donnée Source Raison

3. Durée de conservation

  • Données de profil: Tant que le compte est actif
  • Prédictions: Tant que le compte est actif
  • Adresse IP/logs: 30 jours maximum
  • Après suppression: Données supprimées définitivement dans les 24h
📌 Politique de minimisation: Les données ne sont conservées que le temps nécessaire.

Vous pouvez demander une copie de vos données personnelles. Contactez contact@stockpredi.fr

✏️ Droit de rectification (Article 16)

Vous pouvez corriger vos données via le compte utilisateur ou en contactant le support.

🗑️ Droit à l'oubli (Article 17) — OPÉRATIONNEL

  • Accédez au tab Compte → Supprimer mon compte

6. Partage des données

Vos données ne sont PAS partagées avec:

  • Tiers marketeurs ou publicitaires
  • Services d'analytics (Google, Mixpanel, etc.)
  • Autres utilisateurs de StockPredi
  • Entreprises externes

Partenaires technique:

  • Supabase: Base de données (hébergement EU)
  • Render: Serveur backend (infrastructure cloud)
  • Stripe: Traitement des paiements (tokens seulement)

7. Procédure incident (RGPD Article 33)

En cas de violation de données personnelles:

  1. Détection: Nous analysons la violation
  2. Évaluation: Risque pour les utilisateurs
  3. Notification CNIL (≤ 72h): Rapport formelle à la CNIL
  4. Notification utilisateurs: Si risque élevé
  5. Documentation: Tout incident est enregistré

Contact incident: contact@stockpredi.fr
